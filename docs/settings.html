Settings & commands

Voisu keeps settings to a minimum. On Windows and Mac they live in the settings window and the tray or menu bar menu. On Linux they live in the voisu interface, and every one is also a voisu command.

Windows and Mac settings window Tray and menu bar menu Linux interface Linux Local model Linux commands Where files live

Windows and Mac settings window

Open it from the tray icon (the menu bar icon on a Mac) with Settings…. The first time you run Voisu it shows a setup screen for your two keys (see the Windows or Mac setup guide). After that a sidebar holds these pages:

PageSettingWhat it does
HomeLast TranscriptShows whether Voisu is ready, your Trigger Key, and your last Transcript with Copy. The Transcript is held in memory only.
DictationTrigger KeyThe key you hold to dictate. Ctrl Win on Windows and Control Option on a Mac by default.
DictationPaste automaticallyOn by default. Turn it off and Voisu only puts the Transcript on your clipboard; you paste it yourself.
DictationInformal toneOff by default. On swaps phrases for chat abbreviations like btw and drops the final full stop. Sentence starts and “I” keep their capitals.
DictationOverlay positionWhere the overlay pill sits, bottom centre by default. Move overlay lets you drag the pill anywhere; click ✓ on it or press Enter to save, ✗ or Esc to cancel. Reset position puts it back.
WordsBoost wordsNames and terms Voisu should favour, one per line. Blanks and duplicates are dropped. They're sent to Deepgram and Groq with each Recording.
API keysGroq, DeepgramShows whether each key is saved. Replace pastes a new one, checked with the provider before it's saved. Saved keys are never shown.
GeneralStart at loginStarts Voisu when you sign in. Turned on after your first successful setup.
GeneralStar promptAfter steady use, Voisu may ask for a GitHub star. Turn this off and it never asks. Star on GitHub is always there.
What's newReleasesLists what changed in every release, and what a downloaded update brings before you restart. After an update, Voisu shows what changed once.

General also opens the logs folder and the setup guide. When an update has downloaded, a banner at the top of the window offers Restart to update.

Linux: the voisu interface

Run voisu in a terminal to open Voisu's interface. It works with the keyboard: ← → or 1–4 switch tabs, ↑ ↓ move, Enter acts, ? lists every key, q quits.

  • Home shows whether Voisu is ready to dictate, the Local model in use, and Update available when a new version is out. If something is wrong, it names the problem and the one key that fixes it. d shows every check.
  • Settings holds the rows below, each with a short guide to its choices. When a change needs Voisu to restart, the row says so and r restarts it.
  • Dictionary holds names and terms Voisu should spell your way.
  • History lists recent Recordings. c copies one.
RowChoicesCommand
EngineCloud (needs internet) or Local (stays on this computer)voisu engine
DeliveryPaste, or Copy (you press Ctrl V)voisu delivery
WritingClean or Exactvoisu writing
LayoutPlain, Auto or Sectionsvoisu layout
ToneFormal, or Informal (btw, no final full stop)voisu tone
DeepgramOn or off. Off uses Groq alonevoisu deepgram
Groq key, Deepgram keyEnter enters a new key, checked before it's savedvoisu key set
Trigger KeyShown only; your desktop sets itvoisu shortcut
Local unloadNever (default), After 30 min, After 1 hourvoisu local-unload

OverlayMove (drag the pill, ✓ saves, ✗ cancels) or Reset (bottom centre)voisu overlay-position

If Voisu isn't set up yet, voisu opens straight on setup. voisu setup opens the same screens any time.

Linux: switch to a Local model

Local transcription runs on Linux only, on your own GPU or CPU, with no internet once it's installed. The Windows and Mac apps use Cloud.

  1. Run voisu and open Settings (2). If Local is already installed, pick Engine → Local and you're done.
  2. Otherwise pick Run setup, and on Where should your speech become text? choose Local.
  3. Install Local? shows how much Voisu downloads, once. Without a GPU it adds No GPU found, so it runs on the CPU, more slowly. Choose Install, or Not now to keep using Cloud. Nothing downloads until you choose Install.
  4. Keep the window open while it downloads and checks the model. If the download stops, Enter tries again and carries on where it stopped.

Setup installs Accurate (distil-large-v3.5, about 780 MB) when it finds a GPU and Fast (small.en, about 265 MB) when it doesn't. To change it later, pick Local model: Auto runs Accurate on a GPU and Fast on the CPU. A model that isn't installed asks before it downloads, for example Download Fast (small.en), 252.6 MiB? y/n, and replaces the installed one at your next Recording.

Local device picks where it runs: Auto uses your best GPU through Vulkan (NVIDIA, AMD or Intel), GPU never uses the CPU, and CPU works anywhere but is several times slower. Voisu never switches to the CPU or to Cloud on its own. The model stays loaded by default, so every Recording starts at once; Local unload frees its 1 to 2 GB of memory after an idle spell, and the next Recording then waits about 15 seconds.

Linux commands

Every setting is also a command, for scripts and agents. Run voisu setup again any time to redo the guided setup. Individual settings:

CommandWhat it does
voisu shortcutShows the Trigger Key your desktop approved.
voisu delivery [paste|copy]Paste the text for you, or only copy it. See Where the text goes.
voisu writing [clean|exact]clean fixes grammar and misheard words. exact keeps your words as spoken.
voisu layout [plain|auto|sections]How much layout Voisu adds. plain adds punctuation only; auto organizes your text when you speak in parts; sections adds headings.
voisu deepgram [on|off]Turns Deepgram streaming on or off.
voisu engine [cloud|local]Transcribe online with Cloud, or on this computer with a Local model you've installed.
voisu tone [formal|informal]informal uses chat abbreviations like btw and drops the final full stop.
voisu local-model [auto|accurate|fast]Which Local model runs. A model that isn't installed downloads only after you agree. See Local model.
voisu local-device [auto|gpu|cpu]Where the Local model runs.
voisu local-unload [off|SECONDS]Frees an idle Local model's memory after this long (30 to 86400 seconds). off, the default, keeps it loaded.
voisu local remove [--yes]Deletes the installed Local model.
voisu overlay-position [move|reset|<x,y>]Prints, moves or resets where the overlay pill sits. <x,y> sets it as fractions of the screen, such as 0.500,0.964 (the default, bottom centre). Needs KDE Plasma or Hyprland.
voisu update-check [on|off]Turns the daily update check on or off.
voisu star / star-prompt [on|off]Opens Voisu's GitHub page to star it, or turns the star request on or off.
voisu dictionary add <term>Adds a name or term to your personal dictionary. remove and list manage it.
voisu key set <groq|deepgram>Saves a provider key, read from standard input. key check checks it.

Controlling the daemon:

CommandWhat it does
voisu toggleStarts or stops a Recording, the same as the Trigger Key.
voisu start / stop / statusControls and inspects the daemon.
voisu service install|start|stop|restart|status|uninstallManages Voisu's systemd user services.
voisu doctor [--verbose]Checks that this computer is ready: portals, Delivery, clipboard, keys.
voisu history [--json]Lists recent Recordings from local history.
voisu export <id>Writes a redacted diagnostic export of one Recording, for a bug report.
voisu update [--check|--dry-run]Updates Voisu through the package manager that installed it. See Updating.
