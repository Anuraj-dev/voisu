Settings & commands

Voisu keeps settings to a minimum. On Windows they live in a small settings window and the tray menu. On Linux everything is a voisu command.

Windows settings window Windows tray menu Linux commands Where files live

Windows settings window

Open it from the tray icon with Settings…. The first time you run Voisu it shows a setup screen for your two keys (see the Windows setup guide). After that it has two tabs: Overview shows whether Voisu is ready and your last Transcript; Settings holds the options below.

SettingWhat it does
Trigger KeyThe key you hold to dictate. Ctrl Win by default.
Paste automaticallyOn by default. Turn it off and Voisu only puts the Transcript on your clipboard; you paste it yourself with Ctrl V.
Overlay sizeSmall, Medium or Large. The capsule previews at the new size when you pick one.
Informal toneOff by default. On swaps phrases for chat abbreviations like btw and drops the final full stop. Sentence starts and “I” keep their capitals.
Boost wordsNames and terms Voisu should favour, one per entry. Blanks and duplicates are dropped. They're sent to Deepgram and Groq with each Recording.
Start at loginStarts Voisu in the tray when you sign in to Windows. Turned on after your first successful setup.
API keysShows whether each key is saved. Replace pastes a new one, checked with the provider before it's saved. Saved keys are never shown.

About shows the installed version, whether an update is waiting, and opens the logs folder. Your last Transcript, with Copy, is on the Overview tab and held in memory only.

Windows tray menu

ItemWhat it does
Settings…Opens the settings window.
Preview overlayShows the capsule so you can see where it appears, without recording.
Test paste (in 3 s)Waits three seconds so you can click into an app, then pastes a sample text there. A quick way to check Delivery into a particular app.
Start at loginSame switch as in the settings window.
Update to v…Appears when a new version has downloaded. Installs it and relaunches Voisu.
Quit VoisuStops Voisu. If an update has downloaded, it installs on the way out.

Linux: the voisu interface

Run voisu in a terminal to open Voisu's interface. It works with the keyboard: ← → switch tabs, ↑ ↓ move, Enter acts, ? lists every key, q quits.

  • Home shows whether Voisu is ready to dictate. If something is wrong, it names the problem and the one key that fixes it. d shows every check.
  • Settings changes Engine, Delivery, Writing, Layout, Deepgram and your keys, with a short guide to each choice. When a change needs Voisu to restart, it offers the restart.
  • Dictionary holds names and terms Voisu should spell your way.
  • History lists recent Recordings. c copies one.

If Voisu isn't set up yet, voisu opens straight on setup. voisu setup opens the same screens any time.

Linux commands

Every setting is also a command, for scripts and agents. Run voisu setup again any time to redo the guided setup. Individual settings:

CommandWhat it does
voisu shortcutShows the Trigger Key your desktop approved.
voisu delivery [paste|copy]Paste the text for you, or only copy it. See Where the text goes.
voisu writing [clean|exact]clean fixes grammar and misheard words. exact keeps your words as spoken.
voisu layout [plain|auto|sections]How much layout Voisu adds. plain adds punctuation only; auto organizes your text when you speak in parts; sections adds headings.
voisu deepgram [on|off]Turns Deepgram streaming on or off.
voisu engine [cloud|local]Transcribe online with Cloud, or on this computer with a Local model you've installed.
voisu dictionary add <term>Adds a name or term to your personal dictionary. remove and list manage it.
voisu key set <groq|deepgram>Saves a provider key, read from standard input. key check checks it.

Controlling the daemon:

CommandWhat it does
voisu toggleStarts or stops a Recording, the same as the Trigger Key.
voisu start / stop / statusControls and inspects the daemon.
voisu service install|start|stop|restart|status|uninstallManages Voisu's systemd user services.
voisu doctor [--verbose]Checks that this computer is ready: portals, Delivery, clipboard, keys.
voisu history [--json]Lists recent Recordings from local history.
voisu export <id>Writes a redacted diagnostic export of one Recording, for a bug report.
