# Allow a Consented Install of a hardware-suggested Local model before a Bakeoff Winner

No Local model has passed the frozen #267 gates, so `production_selection()` stays empty and Local fails closed. Development evidence (2026-10-12, one host, one speaker) shows `distil-large-v3.5-int8` on an NVIDIA GPU is the best English model measured. Raja decided on 2026-10-12 that setup should suggest a Local model for the user's hardware and let the user install and use it.

Voisu adds a second, explicit path beside the Bakeoff default: a **Consented Install**. Setup probes the hardware and shows the suggestion on one line as "Recommended for this computer: <model> (<GPU>)" (Raja, 2026-10-13); that display text does not make it a Bakeoff Winner. The measured figures stay in the development evidence, not on the setup screen. Before anything is fetched the user agrees to a short summary (download size, English only, needs an NVIDIA GPU, runs offline after install); the receipt still records the hash of the full catalog consent text. Admission opens only for a verified receipt of a catalog entry that is marked consent-installable. `production_selection()`, the #267 corpus and the #267 tests are unchanged. A Consented Install is not a Bakeoff Winner, and Voisu never selects one by default.

The suggested model runs a pinned Python 3.12 + CTranslate2 + CUDA stack, which is not proven under the daemon's `MemoryDenyWriteExecute` and `RestrictNamespaces` (see `local_worker/runtime.rs`). The daemon unit keeps both restrictions. The worker runs as a separate `systemd-run --user` transient unit with `PrivateNetwork=yes`, AF_UNIX-only sockets and a read-only system. Every runtime file (the Python build and each wheel) and every weight file is SHA-256 pinned and fetched over the existing HTTPS policy. Once installed, the model runs offline. There is no automatic CPU or Cloud fallback.

Consequences: the CUDA runtime (~2.3 GB) and the weights (~1.5 GB) are downloaded per user, not shipped in the package. NVIDIA is the only supported Local GPU vendor. Fedora evidence is still owed before any supported-platform claim.
