# Offer opt-in Local mode on Windows

Raja decided on 2026-11-21 that Windows gets Local mode. This amends ADR 0013, which shipped Windows cloud-only; the Tauri shell, the Trigger Key, the installer and the updater from that ADR are unchanged. Cloud stays the default, and an existing user sees no change unless they choose Local.

Local on Windows reuses the Linux whisper.cpp path rather than a new engine. The installer carries the same `voisu-local-asr` worker and its whisper.cpp DLLs, built with MSVC, every x86_64 CPU variant and ggml's Vulkan backend, beside the app. While Local is on, the app keeps one worker loaded, with no console window and inside a kill-on-close Job Object, and speaks worker protocol v1, with a manifest that pins the worker, the model and the health clip by SHA-256. The worker prepares once; each Recording sends only `transcribe`, and it is shut down cleanly when Local is turned off. The model is never bundled. After the user consents to the size shown, Settings downloads it into `%LOCALAPPDATA%\Voisu\models`. The download is resumable and cancellable, and the size and SHA-256 are checked before the file is used. DPR local formatting, Tone and Delivery are shared with Cloud.

Windows offers the Linux tiers with the Linux rule: Auto runs Accurate (`distil-large-v3.5`) on a GPU and Fast (`small.en`) on the CPU, and the user can pin either. The worker's `--probe-gpu` names the Vulkan GPU at startup without loading a model; a worker that fails on the GPU restarts on the CPU. An existing Fast install keeps working until the user agrees to download Accurate. Decoding is bounded: if the worker is not done within 30 s plus the length of the audio, it is killed and the user is told. Every Local failure (model missing, a pinned file changed, an unsupported CPU, a load, transcribe or timeout failure) shows one plain message and offers a switch back to Cloud. Voisu never falls back to Cloud on its own, because that would send audio off the machine without the user's choice.

Rejected: bundling the model, which would add 264 to 818 MB to every install; a Windows-only engine such as DirectML or ONNX, which would be a second runtime to pin and maintain; and CUDA, which would tie the GPU path to one vendor and a large runtime, where Vulkan ships in every current GPU driver. Spawning a worker per Recording was replaced by the resident worker: reloading Accurate for every Recording costs seconds the user waits for. macOS shares the Tauri app but stays cloud-only; Local is compiled in only on Windows.

Consequences: the release was merged without a real-Windows test. Decode speed with MSVC-built ggml, on the CPU or through Vulkan, is unmeasured, the GPU path depends on the user's driver, and CPUs without AVX2/FMA/F16C/BMI2 cannot use Local. The second unsigned exe is submitted for Defender review like the app. Plan: `internal/specs/2026-11-21-windows-local-model.md`.
