Getting started

Install Voisu, give it your Deepgram and Groq API keys, and make your first Recording. It takes a few minutes on either platform.

Before you start, create an API key with each provider: Groq and Deepgram. Providers & API keys explains what each one does.

Windows Linux Fedora Arch Debian / Ubuntu Other desktops

Windows

Windows 10 / 11 · x64 · installs for your user, no admin needed

  1. Download the installer.

    Download for Windows Voisu-Setup-x64.exe

  2. Run it. The installer isn't code-signed yet, so SmartScreen may warn on first run: choose More info → Run anyway. Voisu installs for your user account only.

  3. Add your keys. Voisu opens its settings on first launch. Paste your Groq and Deepgram API keys and choose Validate & save. Voisu checks each key with its provider before saving it. Both keys are required.

  4. Dictate. Click into any text field, hold Ctrl Win, speak, and release. The capsule appears while you talk, and your words are pasted where your cursor was.

Voisu now lives in the tray and turns on Start at login after your first successful setup. You can close the settings window; it reopens from the tray's Settings… item.

Linux

Voisu runs as a systemd user service, so nothing needs root after the package is installed. Fedora KDE Plasma on Wayland is the primary target; GNOME, Hyprland and X11 desktops work with the differences noted below.

Fedora

$ sudo dnf copr enable anuraj-dev/voisu
$ sudo dnf install voisu
# optional on-screen overlay:
$ sudo dnf install voisu-overlay

Enable the daemon for your user and run the setup wizard:

$ systemctl --user daemon-reload
$ systemctl --user enable --now voisu.service
$ voisu setup

If you installed the overlay package, turn it on too:

$ systemctl --user enable --now voisu-overlay.service

On KDE Plasma and GNOME, your desktop shows a dialog the first time the daemon starts. Choose the Trigger Key there; the choice persists.

Arch

$ yay -S voisu-bin

To build from source instead, install voisu. The two packages conflict, so pick one. Then run:

$ voisu setup

On Hyprland there is no shortcut dialog, so setup binds the Trigger Key for you: Caps Lock if you accept the default, or Right Alt if you decline or Caps Lock is already bound. It also saves your keys and starts Voisu's services. Using Caps Lock as the Trigger Key stops it toggling caps on that key.

Debian / Ubuntu

Ubuntu 26.04 LTS · GNOME Wayland · amd64

# 1. Add Voisu's signing key.
$ sudo install -d -m 0755 /etc/apt/keyrings
$ curl -fsSL https://anuraj-dev.github.io/voisu/voisu-archive-keyring.asc \
    | sudo tee /etc/apt/keyrings/voisu-archive-keyring.asc >/dev/null

# 2. Add the repository.
$ echo 'deb [signed-by=/etc/apt/keyrings/voisu-archive-keyring.asc arch=amd64] https://anuraj-dev.github.io/voisu stable main' \
    | sudo tee /etc/apt/sources.list.d/voisu.list

# 3. Install.
$ sudo apt-get update && sudo apt-get install -y voisu

Signing key fingerprint
4149 EE38 68B3 6B60 0759 2966 D08B CFDC 3412 5B28

Verify the key first 
# Fetch the key to a temp file and check its fingerprint before trusting it.
$ EXPECT=4149EE3868B36B6007592966D08BCFDC34125B28
$ curl -fsSL https://anuraj-dev.github.io/voisu/voisu-archive-keyring.asc -o /tmp/voisu.asc
$ gpg --show-keys --with-colons /tmp/voisu.asc \
    | awk -F: '$1=="fpr"{print $10; exit}'
# The printed fingerprint must equal $EXPECT before you add the key above.

Then run the wizard:

$ voisu setup

Setup asks for your API keys, enables the daemon and the native GNOME capsule, and uses Ctrl Space as the Trigger Key by default. If it asks, log out and back in, or reboot.

Other desktops (X11, Cinnamon)

X11 sessions have no shortcut portal, so bind the Trigger Key yourself. In System Settings → Keyboard → Shortcuts → Custom Shortcuts, add a shortcut that runs:

$ voisu toggle

On X11 Voisu uses xclip for the clipboard, and its feedback arrives as desktop notifications instead of the capsule.

Your first Recording

  1. Click into a text field: an editor, a chat box, a browser address bar.

  2. Press your Trigger Key. The capsule appears and shows your voice.

  3. Say a sentence, then press the Trigger Key again.

  4. The capsule switches to Processing, then the Transcript lands at your cursor.

If nothing happens, run voisu doctor. It checks the daemon, the shortcut portal, Delivery and your keys, and voisu doctor --verbose explains each result. Troubleshooting covers the common cases.
