Set up Voisu on a Mac

About five minutes. You install Voisu, let macOS open it once, allow three permissions, paste two free API keys, and hold Control Option to dictate anywhere you type.

Apple Silicon only, macOS 13 Ventura or newer. To check, open the Apple menu and choose About This Mac. The Chip line should say Apple M1, M2, M3, M4 or newer. Intel Macs aren't supported.

1. Install 2. Open it the first time 3. Permissions 4. API keys 5. Dictate Updates If something's wrong

1. Install Voisu

  1. Download the disk image.

    Download for Mac Voisu-macOS-arm64.dmg

  2. Open it and drag Voisu onto the Applications folder.

  3. Eject the disk image. From now on, open Voisu from Applications, not from the disk image.

2. Open it the first time

Voisu isn't from the App Store and isn't notarized by Apple yet, so macOS blocks it the first time. You let it through once.

  1. Open Voisu from Applications. macOS says it can't check Voisu for malicious software.

  2. Choose Done. Don't choose Move to Trash; that deletes the app.

  3. Open System Settings → Privacy & Security and scroll down to Security. You'll see a line saying Voisu was blocked.

  4. Choose Open Anyway, then Open Anyway again in the dialog, and enter your Mac password if asked.

That's a one-time step. After it, Voisu opens normally, starts at login, and updates itself without asking again.

3. Allow the permissions

Voisu needs three permissions in System Settings → Privacy & Security. Its window lists any that are still missing, each with an Open System Settings button that takes you to the right list. Turn Voisu on in each.

PermissionWhy Voisu needs it
MicrophoneTo hear you. macOS asks the first time you dictate; choose Allow.
AccessibilityTo paste the text into the app you're typing in. macOS doesn't let apps paste for you without it. Without it, Voisu only copies the text and you press ⌘ V yourself.
Input MonitoringTo notice when you hold the Trigger Key. Voisu only listens for that key; it never reads or changes what you type.

If Voisu isn't in a list, click +, pick Voisu from Applications and turn it on.

Quit and reopen once. macOS often applies Accessibility and Input Monitoring only after the app restarts. Choose Quit Voisu from its menu bar icon, then open it again from Applications.

4. Add your API keys

The setup window asks for two keys, one from Groq and one from Deepgram. Both have free allowances that cover everyday dictation.

  1. Groq: on the 1. Groq card choose Get a free API key, sign in, choose Create API Key, and copy the key (it starts with gsk_ and is shown only once). Paste it into the Groq box.

  2. Deepgram: on the 2. Deepgram card choose Get a free API key, sign in, open API Keys, choose Create a New API Key, and paste it into the Deepgram box.

  3. Leave Start Voisu when I sign in on, then choose Save and start. Voisu checks each key and says You're set when both pass.

The Windows guide walks through both consoles with pictures; the Mac window is the same.

Your keys stay on your Mac. They're stored in the macOS Keychain and sent only to the provider they belong to.

5. Dictate

  1. Click into any text box: a chat, an email, a document.

  2. Hold Control Option and speak. A capsule at the bottom of the screen shows your voice.

  3. Let go. Your words are pasted where you were typing and a green ✓ flashes.

For long dictation, double-tap the Trigger Key for hands-free, then press it once more to finish. Esc cancels. If Voisu can't paste, it copies the text and shows an amber Copied · ⌘V: press ⌘ V to paste it yourself.

Voisu lives in the menu bar, not the Dock. Its menu bar icon reopens the settings window, where you can change the Trigger Key, Informal tone, Boost words, Overlay size, Start at login and your API keys.

Updates

When a new version is ready, a banner appears at the top of the window: Update available. Choose Restart to update; Voisu replaces itself and opens again. Your permissions carry over, so you won't be asked again.

If something's wrong

  • “Voisu can't be opened” or “is damaged”. Do step 2 again: Done, then Open Anyway in Privacy & Security. Open Voisu from Applications, not from the disk image.
  • Holding Control Option does nothing. Check that Voisu is on under Input Monitoring, then quit and reopen Voisu.
  • An amber “Copied · allow Accessibility”. Voisu can't paste without Accessibility, so it only copied the text. Turn Voisu on under Accessibility, then quit and reopen Voisu.
  • Nothing gets heard. Check Microphone in Privacy & Security, and that the right microphone is picked under System Settings → Sound → Input.
  • To remove Voisu. Quit it from the menu bar, then drag Voisu from Applications to the Trash. To remove its settings and logs too, delete ~/Library/Application Support/Voisu.

Logs stay on your Mac, in ~/Library/Application Support/Voisu/logs. Open logs folder in Settings takes you there if you want to attach them to a bug report.
