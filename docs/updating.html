Updating & uninstalling

Windows updates itself. On Linux, Voisu updates with the rest of your system through the package manager you installed it from.

Updating on Windows

Voisu checks GitHub for a new release when it starts and every 6 hours after that. When it finds one, it downloads the installer in the background and checks its signature. Then the tray icon gets a dot and the menu shows Update to v….

  • Choose Update to v… to install now. Voisu relaunches on the new version.
  • Or carry on and choose Quit Voisu later. The update installs as Voisu quits.

You can always download the latest installer yourself and run it over the top: Voisu-Setup-x64.exe. Your keys and settings are kept.

Updating on Linux

Fedora

$ sudo dnf upgrade voisu voisu-overlay

Debian / Ubuntu

$ sudo apt-get update && sudo apt-get install --only-upgrade voisu

Arch

$ yay -Syu

Then restart the daemon so the new version is the one running:

$ systemctl --user restart voisu.service

Release notes for every version are on GitHub releases.

Uninstalling

Windows

  1. Choose Quit Voisu from the tray.

  2. Open Settings → Apps → Installed apps, find Voisu, and choose Uninstall.

  3. To remove your API keys too, open Credential Manager from the Start menu, choose Windows Credentials, and remove groq-api-key.Voisu and deepgram-api-key.Voisu.

  4. To remove settings and logs, delete %APPDATA%\Voisu and %LOCALAPPDATA%\Voisu if they're still there.

Linux

Stop and remove Voisu's user services first:

$ voisu service uninstall

Then remove the package:

# Fedora
$ sudo dnf remove voisu voisu-overlay
$ sudo dnf copr remove anuraj-dev/voisu

# Debian / Ubuntu
$ sudo apt-get remove voisu
$ sudo rm /etc/apt/sources.list.d/voisu.list /etc/apt/keyrings/voisu-archive-keyring.asc

# Arch
$ yay -R voisu-bin

If you installed a local model, remove it before uninstalling with voisu local remove.

Your API keys stay in your desktop keyring until you delete them: open KWallet Manager on KDE Plasma, or Passwords and Keys on GNOME, and remove Voisu's entries. To remove settings, history and anything else Voisu kept:

$ rm -rf ~/.config/voisu ~/.local/state/voisu ~/.local/share/voisu
