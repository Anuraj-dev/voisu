Hold a key, speak. Your words land where you're typing.

Voisu is voice dictation for Linux and Windows. It turns speech into clean text and puts it in the app you were already using: a reply, a doc, a terminal. On Windows you hold Ctrl Win while you talk. On Linux you press your Trigger Key to start and again to stop.

Download for Windows Install on Linux

Free and open source (MIT). Uses your own Deepgram and Groq API keys.

Three beats, no window to switch to.

Voisu sits in the background: the tray on Windows, a user service on Linux. A small capsule floats over your screen while it listens, and gets out of the way when your text arrives.

  1. Recording

    Press and talk

    Hold Ctrl Win on Windows, or press your Trigger Key on Linux. The capsule shows your voice as it comes in.

  2. Processing

    Let go

    Release the keys, or press the Trigger Key again. Voisu turns the Recording into a clean Transcript with punctuation.

  3. Delivered

    Keep typing

    The Transcript lands in the window you were typing in when you started. If it can't land there, Voisu keeps it for you instead of dropping it.

Built to get the words right and put them in the right place.

Dictation is only useful if you can trust it with a half-written email. Voisu is careful about what it hears, where it types, and what it keeps.

Two providers, one Transcript

Deepgram streams while you talk. When you stop, Groq transcribes the whole Recording. Voisu reconciles the two into one Transcript, so a dropped stream or a misheard word in one doesn't cost you the sentence.

Lands where you were

On Windows, text goes to the window that had focus when you started, even if you clicked away, and your clipboard is put back afterwards. Terminals get their own paste chord.

Nothing vanishes

If a paste can't land, Voisu tells you why and keeps the Transcript: on your clipboard, or one click away under Last transcript on Windows.

Your keys, your keyring

API keys live in your desktop keyring or Windows Credential Manager. Logs and history stay on your machine.

No root, no raw input

On Linux, Voisu uses your desktop's portals for the shortcut and typing. It never needs uinput or access to input devices.

Hands-free when you need it

On Windows, double-tap Ctrl Win to keep recording without holding the keys; press the chord again to stop. Esc cancels.

Say the punctuation

On Linux, speak marks the way you'd read them: “dash dash”, “slash”, “quote … unquote”, “new paragraph”, or “first … second …” for a numbered list.

Pick your system.

Every channel installs the same Voisu. After installing, voisu setup (Linux) or the settings window (Windows) asks for your API keys and you're ready.

Fedora

KDE Plasma or GNOME on Wayland · RPM from COPR, with an optional overlay package

1Install

$ sudo dnf copr enable anuraj-dev/voisu
$ sudo dnf install voisu
# optional on-screen overlay:
$ sudo dnf install voisu-overlay

2Finish setup

Enable the user daemon, then add your API keys. The first time you dictate, your desktop asks you to confirm the shortcut; that choice sticks.

$ systemctl --user daemon-reload
$ systemctl --user enable --now voisu.service
$ voisu setup

Optional overlay (install voisu-overlay first):

$ systemctl --user enable --now voisu-overlay.service

Arch

Arch Linux · AUR, prebuilt or from source

1Install

$ yay -S voisu-bin

Build from source instead with yay -S voisu. The two packages conflict, so pick one.

2Finish setup

On Hyprland, setup saves your API keys, writes the trigger binding and starts Voisu's services.

$ voisu setup

Debian / Ubuntu

Ubuntu 26.04 LTS · GNOME Wayland · amd64 · the signed apt repository on this site

1Install

# 1. Add Voisu's signing key.
$ sudo install -d -m 0755 /etc/apt/keyrings
$ curl -fsSL https://anuraj-dev.github.io/voisu/voisu-archive-keyring.asc \
    | sudo tee /etc/apt/keyrings/voisu-archive-keyring.asc >/dev/null

# 2. Add the repository.
$ echo 'deb [signed-by=/etc/apt/keyrings/voisu-archive-keyring.asc arch=amd64] https://anuraj-dev.github.io/voisu stable main' \
    | sudo tee /etc/apt/sources.list.d/voisu.list

# 3. Install.
$ sudo apt-get update && sudo apt-get install -y voisu

Signing key fingerprint
4149 EE38 68B3 6B60 0759 2966 D08B CFDC 3412 5B28

Verify the key first 
# Fetch the key to a temp file and check its fingerprint before trusting it.
$ EXPECT=4149EE3868B36B6007592966D08BCFDC34125B28
$ curl -fsSL https://anuraj-dev.github.io/voisu/voisu-archive-keyring.asc -o /tmp/voisu.asc
$ gpg --show-keys --with-colons /tmp/voisu.asc \
    | awk -F: '$1=="fpr"{print $10; exit}'
# The printed fingerprint must equal $EXPECT before you add the key above.

2Finish setup

Setup asks for your API keys, enables the daemon and the native GNOME capsule, and uses Ctrl Space by default. If it asks, log out and back in, or reboot.

$ voisu setup

Windows

Windows 10 / 11 · x64 · installs for your user, no admin needed

1Install

Download for Windows Voisu-Setup-x64.exe

The installer isn't code-signed yet, so SmartScreen may warn on first run: choose More info → Run anyway.

2Finish setup

Voisu opens its settings on first launch: paste your Groq and Deepgram API keys. Then hold Ctrl Win, speak, and release. Voisu lives in the tray and updates itself when a new version is out.

Install with your agent

Paste this into Claude Code, Codex or another agent that can run terminal commands. It installs Voisu for your system; you type your API keys into Voisu's own setup. How it works

Install Voisu on this computer: read https://anuraj-dev.github.io/voisu/agent-install.md and follow it step by step. Never ask me for API keys in this chat; I'll type them into Voisu's own setup.

Every GitHub release also carries the .deb, a tarball and SHA256SUMS. New here? Getting started walks through the first Recording on each system.

No account. You talk to the providers directly.

Voisu has no sign-up and no server of its own in the middle. Your audio goes only to the speech providers you configure, using your own API keys, and you pay them for what you use.
